# 🥤 Coca-Cola Interactive Landing Page

A modern and responsive Coca-Cola themed landing page built using **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**. The project showcases Coca-Cola products, company history, premium ingredients, interactive product cards, anime sticker gallery, and a clean responsive UI.

---

## ✨ Features

- 🎨 Modern Responsive UI
- 📱 Mobile Friendly Navigation
- 🥤 Coca-Cola Product Showcase
- 📖 History & Brand Information
- 🧪 Ingredients Section
- 📋 Product Details Viewer
- 🖼️ Interactive Anime Sticker Gallery
- 📥 Sticker Download Feature
- ⚡ Smooth Scrolling Navigation
- 🎯 Clean Component-Based Architecture
- 🌙 Theme Support Ready

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Sujal-verma777/coca-cola-landing-page.git
```

Move into the project

```bash
cd coca-cola-landing-page
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```
